# search_only trials run under the OLD sandbox regime

These six trials (f01-f06, search_only) were produced during the first pilot
pass, using `general-purpose` subagents under prompt-level tool constraints,
because the purpose-built `solver-web` agent had been created mid-session and
was not yet registered.

They are preserved verbatim and NOT discarded. They are excluded from the
headline exp001 numbers only because the same six questions were re-run under
the repaired, tool-enforced `solver-web` sandbox so that the whole
`search_only` condition sits in one regime.

That makes these six a small, unplanned natural experiment on the sandbox
regime itself: same questions, same prompts, same model, different tool
enforcement. The comparison is reported in the exp001 report under
"Infrastructure and sandbox findings".
